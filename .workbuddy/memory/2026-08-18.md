- 现象: admin/editor 登录均报 code=1003 密码错误

- 修复: 用 Python bcrypt 重新生成 admin123 的哈希($2a$ 前缀, cost 10), 替换 data.sql 两行
- 需要重新执行 data.sql (自带清理逻辑, 可安全重复执行) 后生效

## 修复: 文章编辑报 Column 'cover' cannot be null
- 现象: 编辑文章保存时报 DataIntegrityViolationException, UPDATE cms_article 时 cover 为 null
- 根因: 前端文章表单没有 cover 字段(未回显未提交) + ArticleRepository.update() 未做 null 兜底(insert 有, update 没有), null 传入 NOT NULL 的 cover 列
- 修复:
  - 后端 ArticleRepository.update(): summary/content/cover/seo_title/seo_description 为 null 时转 "", category_id 转 0 (与 insert 保持一致)
  - 前端 article/index.tsx: 表单增加"封面图 URL"输入框, 编辑回显补 cover, 新增默认 cover: ''
- 验证: tsc 零错误; 后端代码改动需重启后端生效
